🧬 Breast Cancer Prediction & Deep Analytics Dashboard
📌 Project Overview
This project is an end-to-end Machine Learning pipeline and interactive web application designed to analyze and predict Breast Cancer outcomes based on clinical data.

Instead of overwhelming the user with complex genomic data, this application focuses on highly interpretable, layman-friendly clinical features (such as Age at Diagnosis, Tumor Size, Tumor Stage, and Therapy Status). The project features a deep Exploratory Data Analysis (EDA) dashboard and an intuitive prediction interface powered by state-of-the-art machine learning algorithms.

✨ Key Features
🩺 Layman-Friendly Features: Carefully selected clinical features that are easily understandable by the general public and medical staff alike.

📊 Deep Analytics Dashboard: An interactive Streamlit dashboard showcasing survival distributions, correlation heatmaps, and feature importance.

🤖 Advanced Machine Learning: Includes multiple robust models:

Random Forest

XGBoost

AdaBoost

Decision Tree

⚙️ Hyperparameter Tuning: Automated optimal parameter selection using GridSearchCV to ensure the highest predictive accuracy.

🌐 Interactive Web Application: A seamless UI built with Streamlit, allowing users to input patient data and receive real-time predictions.

🛠️ Technology Stack
Language: Python

Data Processing: Pandas, NumPy

Machine Learning: Scikit-Learn, XGBoost

Visualizations: Matplotlib, Seaborn

Web Framework: Streamlit

Environment: Python Virtual Environment (venv)
